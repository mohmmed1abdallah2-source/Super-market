# Global Enterprise Supermarket & Retail ERP

تطبيق Flutter لإدارة سوبرماركت ونقاط بيع ومخزون وحسابات، بواجهة عربية RTL، وتشغيل محلي Offline-first باستخدام SQLite. نطاق المنتج هو إدارة البيع داخل المتجر، وليس إنشاء متجر إلكتروني.

## النطاق الوظيفي

- كتالوج أصناف متعدد الوحدات والباركود وأسعار التجزئة والجملة.
- قراءة EAN-13 وباركود ميزان قابل للتهيئة.
- شاشة POS متعددة الفواتير.
- دفتر «له وعليه» وسندات قبض وصرف وقيود محاسبية.
- مخزون ودفعات FEFO وجرد وإتلاف وتحويل بين المستودعات.
- طابور مزامنة محلي يحتفظ بهويات العمليات لإعادة المحاولة.

## المعمارية الحالية وحدودها

- SQLite هو مخزن التشغيل المحلي؛ تحفظ العمليات محليًا أولًا.
- يوجد خادم Dart/Shelf وطبقة PostgreSQL تدعم حاليًا مزامنة ذرية لعمليات الأطراف والمبيعات والسندات والمشتريات والجرد والإتلاف والتحويل.
- محرك SQLite يقبل حقن `ApiClient` لإرسال طابور المزامنة. إعداد عنوان API وجلسة التطبيق الفعلية يظل جزءًا من تهيئة النشر والعميل.
- ما زالت شيفرة Firebase/Firestore موجودة كتكامل اختياري/قديم؛ لا تخلط بينها وبين مسار PostgreSQL API ولا تشغّل مسارين لنفس البيانات دون قرار انتقال موثق.
- مصادقة API تستخدم جلسات حسابات opaque محفوظة كـ hash في قاعدة Control Plane، وتتحقق من المتجر النشط والعضوية والصلاحيات قبل أي عملية تشغيلية.
- توجيه المبيعات والمزامنة والمخزون والمشتريات والحسابات أصبح request-scoped: كل طلب يبني مستودعاته على اتصال قاعدة المتجر المستخرج من الجلسة، ولا يستخدم اتصال PostgreSQL تشغيليًا مشتركًا.
- يحتفظ Control Plane بمرجع database_key فقط؛ ويجب أن يحقن النشر ERP_STORE_DATABASES_JSON من مدير الأسرار. الطلب يفشل مغلقًا إذا لم يكن الربط READY أو لم تتوفر بيانات الاتصال.
- اجتاز اختبار PostgreSQL تكامليًا قاعدتين منفصلتين لهما branch_id متطابق مع إثبات أن كل متجر يقرأ بيانات قاعدته فقط. هذا يثبت آلية التوجيه في CI، ولا يعني أن أسرار الإنتاج أو قواعد المتاجر الفعلية قد أُعدت.
- عزل ملفات SQLite المحلية لكل متجر على Android/Windows/Web ما زال يحتاج تنفيذًا منفصلًا؛ لا يُدّعى اكتمال العزل المحلي متعدد المتاجر.
- لا تضع كلمات مرور PostgreSQL أو رموز الجلسات أو مفاتيح الخدمات داخل التطبيق أو المستودع.

## إنشاء ملفات المنصات أول مرة

إذا لم تكن ملفات المنصة موجودة في نسخة العمل المحلية، ولّدها بواسطة Flutter SDK:

```bash
flutter create --platforms=android,windows .
flutter pub get
dart format .
flutter analyze
flutter test
```

## التشغيل المحلي

```bash
flutter run
```

بيانات الدخول المحلية الافتراضية الموجودة في بعض إعدادات التطوير ليست آمنة للإنتاج. يجب استبدالها بنظام هوية موثوق وتطبيق صلاحيات حقيقية قبل أي استخدام فعلي.

### إنشاء جلسة الجرد
يدعم الخادم الآن `POST /v1/inventory/stocktaking` لإنشاء جلسة `COUNTING` تحتوي سطور الأصناف والدفعات والكميات المعدودة في معاملة واحدة. لا يغيّر الإنشاء المخزون؛ يتم ذلك فقط بعد طلب الاعتماد. راجع `docs/openapi_v1.yaml` وسجل التطوير. نتائج CI لهذا التغيير لا تُعد ناجحة حتى تظهر على commit الجديد.
